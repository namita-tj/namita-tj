A desktop application developed to automate hardware testing workflows.

An applied AI project exploring information extraction and retrieval from complex technical documentation.

- Evaluated on a 151-page technical document

## 💡 Engineering principles

The principles that guide how I approach software and AI engineering.

| Principle | How I apply it |
|:--|:--|
| **Evidence over assumptions** | Measure, test and validate before making claims. |
| **Reliability by design** | Build for edge cases, uncertainty and failure. |
| **Human-centred AI** | Keep human oversight where automated decisions need validation. |
| **Reproducibility** | Prefer traceable experiments, documented decisions and automated tests. |
| **Practical engineering** | Optimise for real-world usefulness, not just impressive demos. |
